# Total Transport University Management System

A comprehensive **University Transport Management System** designed to efficiently manage university transportation operations. The system includes **live bus tracking, fee-pending management, driver details, student-to-bus allocation, vehicle information, announcements, and an analytical dashboard** for monitoring and decision-making.

### Key Features

* 🚌 Live Bus Tracking
* 💰 Pending Fees Management
* 👨‍✈️ Driver Details & Management
* 👨‍🎓 Bus-Specific Student Details
* 🚍 Vehicle Details & Management
* 📢 Announcements
* 📊 Dashboard with Analytics and Reports
* 🔐 Admin and User Management
